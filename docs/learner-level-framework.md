# 学习者水平判断 · 学习框架

> 状态：P1+P2 已实施（2026-08-13，schema v8：`attempts.direction` 持久化；画像聚合 + 难度预算注入备课与审查）；P3 起未实施
> 范围：`kaomoji-english-tutor` 的适应能力——判断用户英语水平，作为备课依据
> 关联文档：`adaptive-tutor-design.md`（导师流水线整体设计）

## 1. 问题

当前备课对用户水平零感知：课程难度来自固定假设（"中级学习者"），备课输入只有最近会话主题和已学内容清单（仅用于防重复）。初学者收到长难句会挫败，高水平用户收到简单词会无聊。

目标：利用用户的历史答题记录，估计其英语水平，并以此为依据动态调整备课难度与侧重点。

## 2. 设计哲学：恒温器，不是温度计

不追求一次性测准一个绝对等级（如 CEFR）——从有限的答题记录无法可靠标定绝对等级，测错也没有纠偏机制。

改为**闭环校准**：

- 难度用**可操作的旋钮**表达（句长、从句复杂度、词汇词带、错误侧重），而不是抽象标签；
- 用**新卡首答成功率是否落在甜区**作为反馈信号，持续微调；
- 定错了会自我纠偏；CEFR 等级仅作为给用户看的展示层标签，不参与控制。

## 3. 三个组成部分

### 3.1 学习者画像（Profile）——"用户现在是什么样"

从答题记录聚合出的多维事实，分维度独立估计（用户可能词汇强、句法弱）：

| 维度 | 含义 | 主要信号 |
| --------- | ------------- | --------- |
| 句法产出 | 能稳定产出多复杂的句子 | 句子卡渐进级别（主干→扩展→完整长句）的首轮到达分布 |
| 词汇召回 | 单词/词组的主动回忆能力 | 双向回忆正确率（中→英产出比英→中识别更能说明问题） |
| 错误画像 | 薄弱点在哪 | 答案评价产出的错误分类（语法/搭配/词序/拼写/词义）频率 |
| 辅助依赖 | 表面正确率的含金量 | 提示/翻面的使用比例 |
| 学习节奏 | 学新东西快不快 | 新卡首答成功率、遗忘率 |

每个维度附带**证据量/置信度**：证据不足时该维度不允许偏离先验太远。

### 3.2 难度预算（Budget）——"下一次备课应该什么样"

由画像推导出的具体备课约束：

- **句长区间**（如 12–18 词）
- **句法复杂度菜单**（如：单一从句为主，暂不使用分词嵌套）
- **词汇词带**（如：常用词为主，每句生词 ≤2）
- **错误侧重**（如：用户搭配错误多 → 例句侧重地道搭配）
- **爬坡方向**：巩固（consolidate）还是拉伸（stretch，i+1）

预算必须是**可客观检查**的：课程审查环节据此判定"句子超词数上限"并打回，使难度控制可强制执行，而非写在提示词里的愿望。

### 3.3 校准回路（Calibration Loop）——"定错了怎么办"

```
答题记录 → 聚合画像 → 推导预算 → 备课与审查
   ↑                                  │
   └────── 新卡首答成功率反馈 ←────────┘
           持续 >85% → 升一档
           持续 <50% → 降一档
           60–80%   → 甜区，不动
```

## 4. 稳定性与冷启动

- **防震荡**：升降档都要求持续证据（如连续约 10 次新卡首答越阈），单日状态差不调档；
- **置信度门控**：某维度证据量不足时，最多偏离先验一档；
- **冷启动先验**：默认"中级"（即现状行为，完全不变）；支持用户自报水平作为先验或硬覆盖。

## 5. 数据基础

已有：每次答题的答案原文、对错/部分对判定、错误分类、辅助级别、掌握阶段、FSRS 状态，均已持久化，跨会话累积。

已知缺口（已补，P1）：单词/词组回忆的**作答方向**（中→英还是英→中）已随答题记录持久化（`attempts.direction`，schema v8）。存量历史记录该字段为 NULL（未知），聚合时按缺失处理。

原则：水平估计使用**确定性聚合**（统计查询），不让 LLM 参与估计本身；LLM 只消费画像与预算来备课。

## 6. 透明度

用户可查看当前画像、所处难度档位和校准状态；展示层可将档位粗略映射为 A2–C1 便于理解，但控制回路只使用内部档位。

## 7. 分阶段路径

1. **P1 数据补课**（已完成）：持久化回忆作答方向。无行为变化。
2. **P2 画像 + 注入**（已完成）：确定性聚合画像 → 推导客观难度预算 → 备课提示词与课程审查接入预算。预算可被客观检查（句长区间/生词上限），超出即被审查打回；冷启动先验为 B1（即原行为）。最小完整闭环已可用（全部测试通过）。
3. **P3 校准回路**：基于新卡首答成功率的自动调档 + 防震荡。
4. **P4（可选）**：用户自报水平覆盖。

每阶段独立可验证、可回滚；P1+P2 即已可用。
